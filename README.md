Shopping List
https://a2-connordunkley.onrender.com/

This web application allows the creation of a shopping list. Specify an item, a cost for the item, and how many you need, and it will be added to the list and a total cost will be tallied for the cost of all items on the list. Additionally, clicking the red X next to an item will remove it from the list and update the total accordingly. 

## Technical Achievements
- **Tech Achievement 1**: Using single page web design
The page accepts form submissions, displays the shopping list/total, and allows deletion of items on the list from index.html.


### Design/Evaluation Achievements
- **Design Achievement 1**: Using 2 think aloud protocols

Think Aloud Protocol #1:
Last name: Heroux (not part of class)
Complaints: NaN could be displayed if letters/symbols were inserted into the "Cost? $" and "How many?" fields.
Comments: The user connected to the website with an apple watch and the styling did not display the site well
From this feedback: I changed the "Cost? $" and "How many?" fields to number fields, and changed the styling to resize the window based on the screen size of the user. 

Think Aloud Protocol #2:
Last name: Lachut (not part of class)
Complaints: There is no 'recently deleted' list to re-add previously removed items, and there is no dyslexia font option
Comments: Colors were easy on the eyes and the UI was easy to use
From this feedback: A Recently deleted items list and a dyslexia font option could be added if this project were to be expanded further.
